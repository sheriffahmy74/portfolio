Inside Lamma

Clean Architecture, layer by layer

  1. 01 · UIWidgets that only render state

    Screens listen to a Cubit and rebuild. No business logic in the UI.

  2. 02 · CubitOne Cubit per screen

    Each Cubit calls use cases and emits loading, success or failure states.

  3. 03 · RepositoryDomain knows nothing about Supabase

    Repository interfaces return Either<Failure, T>. Swapping the backend means rewriting the data layer only.

  4. 04 · SupabaseMoney and capacity live on the server

    Row-Level Security, atomic RPCs and a verified payment webhook. The client never confirms its own payment.
